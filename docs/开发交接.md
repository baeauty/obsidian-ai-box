# AI Box 插件第一版交接

## 已实现

独立 Obsidian 桌面插件，沿用 Agent 全局规则文件接入，不引入 MCP。提供当前库初始化、DSH / Claude / Codex 接入、预览、原文备份、冲突检查、解除和撤销。规则模板不含个人知识或机器固定路径，自动精选沉淀默认关闭。

## 已验证

TypeScript 编译、发布构建、18 项自动测试通过。包括真实临时文件的备份恢复与冲突处理、初始化幂等、插件启动与设置页面的模拟 Obsidian API 集成测试。

测试环境为 Windows；模拟 API 集成测试不等于真实 Obsidian 桌面加载验证。CI 已准备三个桌面系统矩阵，实际云端执行状态需单独核查。

## 接续

1. 在独立空库内启用插件，按 `docs/验收.md` 核查真实界面、预览取消与应用。
2. DSH 桌面版可能使用自己的配置目录，先核查实际入口，不假定终端环境变量等于桌面进程环境变量。
3. Agent 新会话分别验证检索、精选写回和复用；未通过前不标记功能全链路已验收。
4. 完成验收后再决定公开仓库、发布 Release 或申请 Obsidian 社区市场上架。

不要为测试关闭沙箱或改写现有供应商、凭据及配置管理器数据库。升级默认不会覆盖已有库的规则文件。

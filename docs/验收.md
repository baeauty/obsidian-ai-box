# 第一版验收

## 自动测试

执行 `npm test` 和 `npm run package`。测试使用临时目录，不操作真实知识库或真实 Agent 配置。检查发布包只含 main.js、manifest.json、styles.css，无个人路径、笔记、data.json 或凭据。

## Obsidian 桌面实测

1. 在独立空库手动安装并启用 AI Box。
2. 打开设置和侧栏入口，预览初始化；取消应不写文件，应用应生成模板，重复初始化应跳过已有文件。
3. 编辑一篇模板再初始化，确认内容保留。已有库的自定义 SCHEMA.md 同样保留。
4. 将全局规则路径先设为独立测试目录中的 AGENTS.md / CLAUDE.md，写入人工偏好。
5. 预览接入并取消，确认未变化；应用后确认保留人工偏好，且备份内容正确。
6. 重复应用不重复插入；开启自动沉淀并重新应用后指令发生对应变化。
7. 操作另一库时出现改绑提示。未绑定当前库时不能解除。
8. 接入后修改全局规则，再撤销，应拒绝整文件恢复；解除当前库应保留人工新增内容。
9. 未修改过的入口可以撤销到上一快照。卸载插件不会删知识文件，也不会自动解除入口。

## Agent 实测

使用插件“打开验收指南”生成虚构松果演练及记录模板。分别记录工具版本和真实工具读取证据，检索、写回、另一新会话复用分别验收。未安装的 Agent 只测配置逻辑，不标记行为通过。

权限不足时记录具体阻塞。不要关闭沙箱、改供应商或从已有本机成功推断另一台电脑已经成功。
